# Security and privacy

Photo Renamer operates on local folders and does not upload photos or collect
telemetry. The release package does not include credentials or account setup.

For a security issue, use the repository's private vulnerability reporting
feature when available. If it is unavailable, open a minimal issue asking for
a private reporting channel without sharing exploit details or private data.

Do not post recovery files, local history, full personal paths, private photos,
tokens or credentials in public issues. A minimal reproduction using generated
sample folders is usually enough.

Undo restores names, not edited or deleted contents. Back up important
collections. See [AUDIT.md](AUDIT.md) for the review scope and limitations.
