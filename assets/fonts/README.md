# Bundled typefaces

IBM Plex Sans (Regular and Medium) and IBM Plex Mono (Regular), by IBM.
Unmodified fonts from [IBM/plex](https://github.com/IBM/plex), commit
`71f558992315a12ca1f06a2215d57962a1992162`.

Licensed under the [SIL Open Font License 1.1](OFL.txt). The build embeds them
in the executable. The app loads them privately for its own process; it does
not install fonts into Windows or download fonts at runtime.

The regular and medium Sans files come from
`packages/plex-sans/fonts/complete/ttf`; Mono comes from
`packages/plex-mono/fonts/complete/ttf`.
